Animated Concepts

Animated Concepts

A practical demonstration of the CSS and JavaScript animation techniques used across this portfolio. Each demonstration can be tested directly on this page.

Motion settings

Motion is enabled. Animations and transitions are active. Motion is reduced. Animations are paused or shown in their final state.

This page also respects the operating system's prefers-reduced-motion setting. The button on the right overrides it for this browser and remembers your choice.

Demonstration 01

Typing text animation

A line of text types itself, pauses, deletes and then moves on to the next phrase. This is the same effect used in the home page hero.

I am a Computer Science Student

The typing demonstration cycles through: Computer Science Student, Aspiring Software Developer and Technology Enthusiast.

JavaScript concept: setTimeout schedules each small step. A character counter and a boolean (deleting) track whether the text is growing or shrinking, and String.prototype.slice displays part of the phrase. The cursor blink is a CSS @keyframes animation.

Demonstration 02

Hover and focus animation

Interactive cards lift, glow and rotate their icon when hovered with a mouse or focused with the keyboard. The primary buttons across the site use the same idea.

↗

Lift

The card moves up and gains a soft shadow.

✦

Glow

The border and shadow take on the blue accent colour.

◈

Icon motion

The icon rotates slightly and grows at the same time.

Hover each card with a mouse, or press Tab to focus them with the keyboard.

CSS concepts: the :hover and :focus-visible pseudo-classes change styles, while transition, transform and box-shadow make the change smooth instead of instant. Focus styles keep the same effect available to keyboard users.

Demonstration 03

Scroll reveal animation

The four blocks below appear as they enter the viewport. Use the replay button to hide them and watch the effect again.

Block 01
Block 02
Block 03
Block 04

JavaScript concept: IntersectionObserver watches when an element enters the viewport. When it does, JavaScript adds the is-visible class. CSS handles the fade and upward movement through opacity, transform and transition.

Demonstration 04

CSS keyframe animation

This floating orb and expanding ring run continuously using CSS keyframes. The button pauses and resumes the animation.

CSS concepts: @keyframes defines the positions at 0%, 50% and 100%, and animation applies them with a duration and an infinite repeat. animation-play-state pauses the motion without removing the animation.

Accessibility

Motion is optional

Every animation on this site can be turned off with the reduce-motion button. The site also respects the visitor's operating-system preference automatically.
